# 净启助手（CleanLaunch）

Android 广告误触跳转防护工具，当前开发版本：**0.2.0**。

## 本次升级内容
- 针对七猫免费小说（`com.kmxs.reader`）和快搜搜题（`com.questions.liteai`）增加定向监控。
- 检测到广告信号后，监控前台应用切换；若疑似由广告触发外部应用启动，尝试返回原应用。
- 对系统权限控制器中明确标注为身体传感器、运动传感器或陀螺仪的权限请求，尝试点击拒绝，并继续监听后续界面。
- 保留广告跳过按钮识别与本机拦截记录。

## 重要限制
Android 普通陀螺仪读取通常不需要单独的运行时权限；身体传感器权限主要针对心率等人体传感器数据。若应用直接读取普通陀螺仪数据而系统不弹权限框，本工具无法通过无障碍服务阻止该传感器调用。

Android 不向普通第三方应用提供全局取消其他应用 Activity 启动的接口。本项目通过无障碍事件识别广告后的前台切换，并尝试执行返回操作；无法保证拦截所有应用、所有广告或所有跳转，也可能受系统版本、厂商定制和应用页面结构影响。
